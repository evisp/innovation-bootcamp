# Innovation Bootcamp Albania · Website

Site for Innovation Bootcamp Albania (26–30 October 2026), built with MkDocs Material.
Live: https://evisp.github.io/innovation-bootcamp/

## Run locally
    python3 -m venv .venv && source .venv/bin/activate
    pip install -r requirements.txt
    mkdocs serve

## Edit content
Pages live in `docs/`. Styles in `docs/stylesheets/extra.css`.
Diagrams (SVG) in `docs/assets/diagrams/`. Pushing to `main` deploys automatically.
